Dynamic Resonator 1.3.0 — Windows x64
Pneutrino by NeutronStar714

Standalone package:
Extract the ZIP and run Dynamic Resonator.exe. Select your audio device and
input/output channels in the application's audio settings. Start at a low
monitoring volume and avoid routing the speaker output back into the input.

VST3 package:
Extract the ZIP. Copy the complete "Dynamic Resonator.vst3" folder into a
VST3 location scanned by your DAW, such as C:\Program Files\Common Files\VST3.
That system-wide folder may require administrator permission. Rescan plugins
in your DAW. Keep the bundle's Contents directory and all files inside it.

Source and build instructions:
https://github.com/NeutronStar714/pneutrino-dynamic-resonator

These are Release builds. Compilation is checked; broad host/device and
performance validation remains in progress. Historical FL Studio/ASIO4ALL
testing reported underruns at 512 samples and none at 1024. See docs/TESTING.md
in the source repository for the current limits.

The guitar demonstration is provided separately as pr-rec-dynres.mp3.
SHA256SUMS.txt contains checksums for the two ZIPs and the MP3.
