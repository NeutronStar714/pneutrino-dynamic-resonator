Dynamic Resonator 1.3.0, from the Pneutrino series by NeutronStar714.

## Downloads

- **Windows x64 Standalone ZIP:** extract and run `Dynamic Resonator.exe`.
- **Windows x64 VST3 ZIP:** install the complete `Dynamic Resonator.vst3` folder in a location scanned by your DAW, then rescan plugins.
- **pr-rec-dynres.mp3:** the author's guitar effect demonstration, encoded at 320 kb/s from the supplied WAV without changing the performance.
- **SHA256SUMS.txt:** checksums for both packages and the audio demo.

Both formats are built from the tagged source with the pinned JUCE dependency. Build success does not establish compatibility with every host, device or buffer size. Historical FL Studio/ASIO4ALL testing reported underruns at 512 samples and none at 1024; fresh performance testing remains in progress.

This release publishes the existing 1.3.0 implementation. It does not introduce a new DSP version. The source, development record, contributions and third-party notices are available in the repository.
